# קובצי נתונים לדוגמה

למי שלא הביא נתונים משלו, או שרוצה להתחיל מבדיקה בטוחה. כל הנתונים מומצאים.

| קובץ | מה יש בו | כלי שמתאים לו |
|---|---|---|
| `quotes.csv` | הצעות מחיר: לקוח, סכום, תאריך, סטטוס | "אילו הצעות תקועות מעל שבוע" |
| `leads.csv` | לידים: שם, חברה, מקור, שיחה אחרונה, שלב | "מי מהלידים הלך לאיבוד" |
| `shifts.csv` | משמרות: תאריך, עובד, מתוכנן מול בפועל | "איפה יש פערי שעות השבוע" |

הקידוד הוא UTF-8 עם שורת כותרות בעברית. אם אתם מייצאים מאקסל, שמרו כ-"CSV UTF-8".
