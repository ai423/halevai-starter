# עשרת הכללים

איך לעבוד עם Claude Code בלי להיתקע. עמוד אחד. מודפס ומחולק בסיום.

1. **דבר אחד בכל בקשה.**
2. **תוכנית לפני קוד.**
3. **בודקים בכתובת, לא בקוד.**
4. **הלוג הוא הפרומפט.**
5. **כרטיס אפיון לפני מקלדת.**
6. **"הכלי לא עושה" חשוב כמו "הכלי עושה".**
7. **נתקעתם יותר מ-5 דקות? מצמצמים את הבקשה, לא מגדילים את הפרומפט.**
8. **סודות רק במשתני סביבה.**
9. **גרסה ראשונה מכוערת שעובדת מנצחת גרסה יפה שלא עלתה.**
10. **"הבא בתור" הוא רשימה, לא בקשה.**
