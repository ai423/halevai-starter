# חמשת הפרומפטים

לא צריך להמציא פרומפטים. צריך למלא כרטיס טוב ולהעתיק מכאן.
כל מה שבסוגריים מרובעים מחליפים בטקסט שלכם.

## 1. חידוד האפיון
**מתי:** שלב 1, ב-Claude הרגיל (בצ'אט, לא ב-Claude Code)

```
הנה כרטיס אפיון לכלי קטן שאני רוצה לבנות:

[הכרטיס, מהדף]

אל תציע פיצ'רים. תשאל אותי עד שלוש שאלות שהתשובה עליהן תשנה מה בונים, ואז תחזיר לי את הכרטיס מחודד, באותו מבנה, בלי להוסיף שום דבר שלא אמרתי.
```

## 2. הבנייה הראשונה
**מתי:** שלב 3, ב-Claude Code, אחרי שהכרטיס הועתק ל-SPEC.md

```
קרא את SPEC.md. בנה רק את מה שכתוב תחת "פלט", עם הקלט שכתוב תחת "קלט". קודם הצג לי תוכנית של עד 5 שורות ומה יהיה בעמוד, ורק אחרי שאאשר תתחיל. תקפיד על מה שכתוב תחת "הכלי לא עושה".
```

## 3. הצעד הבא
**מתי:** שלב 3, אחרי כל מיזוג ובדיקה בכתובת

```
בדקתי בכתובת. [מה עבד / מה לא]. הדבר הבא, ורק הוא: [שורה אחת מ"הבא בתור"]. תוכנית קצרה קודם.
```

## 4. הלוג הוא הפרומפט
**מתי:** כשהפריסה ב-Vercel נכשלה (Build Failed)

```
הפריסה ב-Vercel נכשלה. זה הלוג:

[הדבקת הלוג מ-Vercel]

תסביר לי במשפט אחד מה קרה, תתקן, ותוודא ש-npm run build עובר לפני שאתה מסיים.
```

## 5. לרוץ לבד
**מתי:** שלב 5, רק אם הכלי שלכם מבוסס על משהו שקורה בזמן (בדיקה יומית, דוח שבועי)

```
אני רוצה שהכלי ירוץ לבד כל יום ב-7:00 בבוקר שעון ישראל, בלי שאפתח אותו. הפעל את ה-workflow הקיים ב-.github/workflows/daily.yml, חבר את scripts/daily.mjs ל[מה הכלי עושה], ותסביר לי איפה אראה שהוא רץ ואיפה אראה אם הוא נכשל.
```

## שני פרומפטים לשעת חירום

**כש-Claude Code בנה יותר מדי:**
```
בטל את כל מה שלא ביקשתי. תשאיר רק [הפלט מהכרטיס]. תוכנית קודם.
```

**כשקובץ הנתונים לא נקרא:**
```
הנה שלוש השורות הראשונות מהקובץ שלי:

[הדבקה]

תתאים את קריאת הקובץ למבנה הזה. שום דבר אחר.
```
